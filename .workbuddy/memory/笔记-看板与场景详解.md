## A. 防 z-fighting 完整论证

**墙体的 5 对共享墙线**（各自生成 0.15m 墙盒 → 六面严格共面）：
`x=15.6 CRO|CMO 12.88㎡ · x=23.8 CMO|CTO 18.48㎡ · x=19.4 COO|CEO 18.48㎡ · z=11.0 CPO|会议室 15.68㎡ · z=16.4 会议室|CFO 14.56㎡`

**余量论证**：相机 `near/far = 0.5/75`，24 位深度缓冲在 25m 处精度 ≈0.07mm → 11mm（8+3）是其 **150 倍**；实测残余最小面间距 5mm。

**地面铺装**：09-11 全场景扫出 14 处同 y 共面重叠。

## C. 性能与场景实现细节

- 基线（冷缓存、无 GPU、沙箱 headless）：FCP 564ms / DOMContentLoaded 3959ms / 8 房模型就位 9295ms。
- 规模：网格 396 / 材质 212 / 三角面 281 万 / 主文件 ~187KB。
- **`hasModels` 分支**：模型包可用 → 跳过程序化兜底家具（否则两套叠加）；CFO 装饰与 GLB 共存；包缺失才走兜底。
- 阴影按需：`shadowMap.autoUpdate=false`，门动画与 `loadRoomShowcase` 后 `needsUpdate=true`。
- 材质缓存：`mcolor()` 只对无 opts 调用走 `_matCache`。
- 模型包构建：`_verify/build_all_models.py`（源 `E:/AI/Workbuddy/office3d-assets/models`）→ 9 类 3.4MB。
- 调试钩子：`__showCount`、`__boardDebug{scene,camera,controls,renderer,doorGroups,doorPickables,toggleDoor,animateToZone}`。
- 截图原理：无 GPU 沙箱下 `page.screenshot()`/`canvas.toDataURL()` 返回全白（renderer 未开 `preserveDrawingBuffer`）。解法：离屏 `WebGLRenderTarget` → `readRenderTargetPixels` → 翻 Y → 手工 zlib 编码 PNG。`grab.mjs` 导出 `encodePNG()` / `rtShot(page,file,W,H,bg)` / `look(page,...)`（**必须先 `look()`** 放开 OrbitControls 限制，否则近景被控件覆盖）。

## D. taskboard 安全与接入清单

- **`server.deny` 黑名单完整内容**：`/inbox/`、`/_shots/`、`/agent-templates/`（`/` 开头 → 前缀匹配）+ `.bak`、`.db`、`.py`、`.md`、`.env`、`.log`（其余 → 子串匹配）。**只放行 `.html` / `.js` / 模型文件**。
- 备份文件命名形如 `x.html.bak_pre_zfight_20260916`，`.bak` 在中间 → 纯后缀匹配会漏，故用子串。
- **`agent-templates/` 8 份模板**（索引见其 `README.md`）：`SPEC.md`（规则唯一真源）· `any-agent-prompt.md`（可直接贴的通用指令）· `粘贴用的短口令.md`（一行版/六行版）· `make-config.py`（生成 `AGENTS.md`/`CLAUDE.md`/`.cursorrules`）· `claim-poll.py`（认领助手）· `一键生成配置.bat` · `录入任务.bat` · `dropbox/README.md`。
- `make-config.py` 参数：`--source/--ip/--port/--project/--dry-run`；产物落 `生成配置/{粘贴.txt, AGENTS.md, CLAUDE.md, .cursorrules}`。
- **`.bat` 注意**：需 UTF-8 无 BOM + `chcp 65001` + `%~dp0` 相对路径 + **CRLF**（LF 会让 `cmd.exe` 静默不执行）。
- **Docker**：`Dockerfile` 基于 `python:3.12-slim`，构建阶段不联网；`docker-compose.yml` 挂载 `./data`、`./tasks-data`、主 HTML、`all-models.js`、配置文件。本机沙箱无 docker，**未实测**。
- **CLI 子命令**：`doctor` `serve` `ingest` `add` `ls` `set` `rm` `export` `seed-demo` `clear` `stats` + `claim` `claims` `approve` `reject` `withdraw` `queue`。
- 数据库自动迁移：`Store._migrate()` 用 `PRAGMA table_info` 找缺失列 → `ALTER TABLE ADD COLUMN`（老库可直接升级）。
