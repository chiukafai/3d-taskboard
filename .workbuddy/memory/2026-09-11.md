### 四、⭐ 本轮最重要的两个方法论坑（务必记住）

1. **`page.screenshot()` / `canvas.toDataURL()` 在本沙箱返回全白（std=0）** —— 根因是 `new THREE.WebGLRenderer({antialias:true, alpha:true})` **没开 `preserveDrawingBuffer`**，且无 GPU 时画布合成被丢弃。
   **解法**：写 `_verify/grab.mjs` —— 渲染到离屏 `WebGLRenderTarget` → `readRenderTargetPixels` → 翻 Y → **手工用 zlib 编码 PNG**。
   导出 `encodePNG(W,H,rgbaTopDown)` / `rtShot(page,file,W,H,bg)` / `look(page,px,py,pz,lx,ly,lz)`（后者会先把 OrbitControls 的 `minDistance` 9→0.05、`maxDistance→200`、极角放开，否则近景相机被控件覆盖）。
   **在这个环境里要出图，一律用 `grab.mjs`，别再试 `page.screenshot()`。**（此前白折腾 6 次）
2. **判"某个 GLB 到底是什么"必须做隔离渲染 + 包围盒实测** —— 靠文件名 `office_monitor` 想当然认为是一台显示器，才导致"两台笔记本各带圆盘托底"。
   做法：`_verify/probe_monitor_face.mjs` 按世界包围盒把目标模型从场景里筛出来、把其它全 hide、从 +Z/−Z/顶三个角度出图 → 一眼看清是"整套工位 + 圆盘"。
   **铁律：`office3d-assets/models/` 里任何模型，先测包围盒 + 隔离出图，再决定怎么摆。**
3. **坐标坑**：`_SHOW` 的 `p` 是**房间局部坐标**（世界 = cx+px, cz+pz），`buildMemWall` 算的是**世界坐标** —— 两者比较前必须转换。
4. `make_compare_v51.py` 页脚文案里 `%` 与 Python `%` 格式化冲突的老问题（同 v5 轮）。
