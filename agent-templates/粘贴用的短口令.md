# 粘贴用的短口令

> **`any-agent-prompt.md` 那段 48 行是"装一次"的，不是每次会话都要贴。**
> 如果你确实需要临时贴（agent 没有持久配置，或者只想让它报一次），用下面这几个短版本。
>
> 换行 ≥ 复制成本。**优先用最短的。**

---

## ① 一行版（最省事 · 前提：那个 agent 能读本地文件）

```
任务上报规则见 C:\Users\Perfect\Desktop\3d-taskboard-main\agent-templates\SPEC.md，每次会话结束前按它上报，source 填 <你的名字>。
```

把 `<你的名字>` 换成 `workbuddy` / `claude-code` / `hermes` 之类。

**为什么最短**：规则正文留在 SPEC.md 里，改一次全部生效，不用重新贴。

---

## ② 六行版（agent 读不了本地文件时用 · 自带全部信息）

```
【任务上报规则】本会话完成或推进的每件事都要上报到 3D 看板。
地址：POST http://127.0.0.1:8787/api/tasks　（远程把 127.0.0.1 换成机器 IP）
字段：{"title":"必填","dept":"cfo|cto|cmo|ceo|cpo|coo|cro|meeting","status":"todo|in_progress|done|blocked","priority":"high|medium|low","source":"你的名字","desc":"一句话","dept_reason":"判部门的依据"}
判部门：dept = 谁验收（报表→cfo 接口→cto 投放→cmo 发货→coo 需求→cpo 合规→cro 规划→ceo 评审会→meeting）；谁给料写进 collaborators 数组；判不出来就别写 dept（系统会猜，看板会打「部门待核」标提醒人复核）。
未完成的也要报（用 in_progress）；卡住的用 blocked。重复上报=更新，不会变两条。一次会话最多报 3 条。
```

（可选，想让它主动接活再加这一行）

```
想接活就先申请、别自己开工：POST http://127.0.0.1:8787/api/tasks/<任务id>/claim　body {"agent":"你的名字","note":"我能接"}；批准后 GET /api/queue?agent=你的名字 取活。
```

---

## ③ 装一次版（agent 支持持久配置时用 · 之后永久免贴）

把第 ① 行写进下列任一处，**从此不用再贴**：

| agent | 写进哪里 |
|---|---|
| WorkBuddy | 已装成技能：说「记到看板」或 `/看板记一下` 即可 |
| Claude Code | 项目根 `CLAUDE.md`，或全局 `~/.claude/CLAUDE.md` |
| Cursor | 项目根 `.cursorrules`，或 `.cursor/rules/*.mdc` |
| Hermes / 自建 agent | 其 system prompt 字段 |
| 任何支持 `AGENTS.md` 的 | 项目根 `AGENTS.md` |

> 生成这些文件不用手抄：双击 `agent-templates/一键生成配置.bat`，回答 3 个问题即可。
> （`.bat` 未在真实双击环境下实测过，双击没反应就改用 `python agent-templates/make-config.py`）

## ④ 完全不想碰 agent 时

| 场景 | 怎么做 |
|---|---|
| 手动补一条 | 双击 `agent-templates/录入任务.bat`，输入标题回车；或对 WorkBuddy 说「记到看板」 |
| 批量补 | 往 `data/inbox/` 丢一个 `.jsonl` 文件 |
| 看着办 | 打开 `http://127.0.0.1:8787/` 点卡片上的按钮 |
| 有 agent 想接活待你批 | 看板**左下角会亮 🔔**，点开批准或驳回 |
